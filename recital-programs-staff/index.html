Staff — Publish to LiveWhale

Turn a student's approved project file (.json) into the ready-to-paste program HTML for the calendar event. Students never use this page.

Steps

  1. Load the approved .json project file the student sent you.
  2. Check the preview below matches the approved program.
  3. Click Copy for LiveWhale.
  4. In LiveWhale, open the event → Event description → the < > (Source Code) button → paste → Save, then save the event.
